Ornament Controller Instructions

User Guide for the Custom LED Ornament

Turning the Ornament On

1. Install 3x AAA batteries in the battery holder on the back of the ornament - with the negative (flat) side facing the spring in each compartment. (A fresh set of quality batteries should last ~30 days in normal operation with default brightness)

2. Locate the power switch on the right-hand side of the ornament, on the underside of the branches.

3. Slide the switch to the "on" position.

4. The ornament will immediately begin operating in its default mode, alternating between "twinkling" and showing the advent calendar display.

5. The ornament will run for 5 hours from when you turned it on, then sleep until 24 hours after the initial powering-on and continue in that cycle. The result is that it will auto-activate at the same time each day, and run for 5 hours before going to sleep until the next day.

Figure 1: Power Button Location

Setting the Daily Start Time

1. The ornament will automatically start each day at the same time as when you initially turned it on, or when power was most recently restored.

2. To set or re-set the start time, simply turn the ornament off by the switch (or remove the batteries) and turn it back on at the time you want it to start each day.

3. The ornament will now use this time as the daily start time.

4. There is no need to turn the ornament off or on each day - it will automatically cycle for 5 hours on daily.

5. Using the 'Preview Mode' (below) will not affect the daily start time.

Setting the Date

When the ornament is first powered on, it presumes it is December 1st, and starts counting days from there. If you activate it on any other day, you can change the current date as below.

To get into setup mode:

  1. Press and hold the button for 3 seconds until all the LEDs turn off.
  2. When you release the button, the LED for the current day will blink.

To change the date:

  1. Click the button once to advance the date by one day/LED.
  2. Continue clicking to cycle through the days of December (1-25).

Once you're on the correct LED for the day of the month:

  • Wait 10 seconds, or press and hold the button for 2 seconds to continue to brightness setting mode

Figure 2: Button for entering setup mode (advent day / brightness)

Note: The date setting process is designed to be intuitive and requires only a few simple button presses.

Adjusting Brightness

To adjust the brightness level:

  1. After setting the date as above, enter the brightness adjustment mode by pressing and holding the button for 2 seconds, or waiting 10 seconds as noted above.
  2. One LED of each color will light up and start blinking at the current brightness setting. Note that this is peak brightness - and LEDs will normally appear slightly dimmer during regular operation because they fade in and fade out.
  3. Press the button to cycle through the various brightness levels:
    • 10% - Dim setting
    • 25% - Low setting
    • 50% - Medium setting (default)
    • 75% - High setting
    • 100% - Maximum brightness
  4. Once you're done, leave the ornament alone and it will save your settings after 10 seconds and return to normal operation.

Figure 3: Brightness Adjustment Interface

Note: The date and brightness settings are saved to non-volatile memory, so they will persist after power-off.

Normal Operation

The ornament operates in two distinct modes:

Twinkle Mode

The ornament will always display a twinkling pattern that cycles through different LED combinations for approximately 30 seconds, at the chosen brightness level.

Figure 4: Twinkle Mode Animation

Advent Mode

Every 30 seconds, the ornament enters Advent mode where it displays a special pattern that progresses through the days of Advent:

  1. Each day, a new LED pattern appears
  2. On the 25th day, it displays a special celebration pattern
Image: Advent Mode Animation

Figure 3: Advent Day Setting Interface

Automatic Cycling and Sleep Mode

The ornament will turn on and run for 5 hours when you turn the power switch on the first time. It will automatically go into sleep mode after 5 hours, and turn back on again 24-hours from when you first turned it on - so that it will run at the same time each day without any user action.

To have it start at a different time each day, simply turn the ornament off by the switch, and turn it on at the time you'd like it to normally turn on by itself.

Preview Mode

When the ornament is in sleep mode (no LEDs showing), pressing the button once will activate the ornament for 1 hour. This will not affect the normal auto-wake timing.

Troubleshooting

If the ornament is not responding as expected:

  • Ensure the batteries are fresh, or replace with new batteries
  • Try resetting the ornament by turning the power switch off and back on
  • Check that all connections are secure
  • For timing issues, make sure to turn the ornament off and back on at your desired daily start time
